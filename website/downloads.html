dotnet nuget add source ./local-packages

JDBC Driver v0.1.0

2026-03-07 new

Pure Java JDBC driver for OxiDB using the OxiWire binary protocol. Zero dependencies, Java 17+. Works with DBeaver, IntelliJ, and any JDBC-compatible tool.

PlatformArchitectureFileSizeType
All (Java) Platform-independent oxidb-jdbc-0.1.0.jar 38 KB jar Download

JDBC Connection

// Driver class
com.oxidb.jdbc.OxiDbDriver

// URL format
jdbc:oxidb://host:port

// Java usage
Connection conn = DriverManager.getConnection("jdbc:oxidb://127.0.0.1:4444");
Statement stmt = conn.createStatement();
ResultSet rs = stmt.executeQuery("SELECT * FROM users");

// Maven
<dependency>
  <groupId>com.oxidb</groupId>
  <artifactId>oxidb-jdbc</artifactId>
  <version>0.1.0</version>
</dependency>
