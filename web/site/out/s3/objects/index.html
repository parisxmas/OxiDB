S3 · API

Objects

The everyday operations: PUT, GET, HEAD, DELETE, COPY, plus tagging and conditional / range reads.

PUT — upload an object

aws --endpoint-url http://localhost:9000 s3 cp ./avatar.png s3://photos/me.png

With content-type and custom metadata

aws --endpoint-url http://localhost:9000 s3api put-object \
  --bucket photos --key me.png \
  --body avatar.png \
  --content-type image/png \
  --metadata "user_id=123,uploaded_by=alice"

boto3

s3.upload_file("avatar.png", "photos", "me.png", ExtraArgs={
    "ContentType": "image/png",
    "Metadata": {"user_id": "123"}
})

Raw curl

curl -X PUT --data-binary @avatar.png \
  -H "Content-Type: image/png" \
  -H "x-amz-meta-user-id: 123" \
  --aws-sigv4 "aws:amz:us-east-1:s3" \
  --user "minioadmin:minioadmin" \
  http://localhost:9000/photos/me.png

GET — download an object

aws --endpoint-url http://localhost:9000 s3 cp s3://photos/me.png ./download.png

Range requests

Standard HTTP Range header — useful for video streaming, resumable downloads, partial reads.

aws --endpoint-url http://localhost:9000 s3api get-object \
  --bucket videos --key movie.mp4 \
  --range bytes=0-1048575 \
  /tmp/first-megabyte

Conditional GET

aws --endpoint-url http://localhost:9000 s3api get-object \
  --bucket photos --key me.png \
  --if-none-match '"abc123def"' \
  /tmp/me.png
# Returns 304 Not Modified if ETag matches

HEAD — metadata only

aws --endpoint-url http://localhost:9000 s3api head-object \
  --bucket photos --key me.png

Returns size, content-type, ETag, last-modified, and any custom x-amz-meta-* headers.

DELETE — remove an object

aws --endpoint-url http://localhost:9000 s3 rm s3://photos/me.png

Batch delete (up to 1000 keys)

s3.delete_objects(Bucket="photos", Delete={
    "Objects": [{"Key": "old1.jpg"}, {"Key": "old2.jpg"}, {"Key": "old3.jpg"}]
})

COPY — server-side duplicate

aws --endpoint-url http://localhost:9000 s3 cp \
  s3://photos/me.png s3://backups/photos/me.png

The server copies the bytes locally — no download/upload round-trip via the client.

boto3

s3.copy_object(
    Bucket="backups", Key="photos/me.png",
    CopySource={"Bucket": "photos", "Key": "me.png"}
)

Tagging

# Set tags
aws --endpoint-url http://localhost:9000 s3api put-object-tagging \
  --bucket photos --key me.png \
  --tagging '{"TagSet":[{"Key":"env","Value":"prod"},{"Key":"owner","Value":"alice"}]}'

# Read tags
aws --endpoint-url http://localhost:9000 s3api get-object-tagging \
  --bucket photos --key me.png

# Clear tags
aws --endpoint-url http://localhost:9000 s3api delete-object-tagging \
  --bucket photos --key me.png

What's stored

Each object carries: content-type, custom metadata (x-amz-meta-*), tags, ETag (CRC32 hex), creation timestamp, byte size. ETag changes on every PUT.

Limits

  • Single-PUT object size: 5 GiB. Use multipart upload for larger.
  • Object key length: 1024 bytes UTF-8.
  • Custom metadata: 2 KB total per object.
  • Tags: 10 per object, 128 chars per key, 256 chars per value.
