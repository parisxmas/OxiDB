<h2><code>find</code> / <code>find_one</code></h2>
<p>Read documents from a collection. <code>find</code> returns an array; <code>find_one</code> returns a single document or <code>null</code>.</p>

<h3>Signatures</h3>
<pre><code class="lang-rust">find(collection, query)        <span class="co">// → array</span>
find_one(collection, query)    <span class="co">// → object or null</span></code></pre>

<h3>Find one by id</h3>
<pre><code class="lang-rust">proc get_user(id) {
    let u = find_one(<span class="str">"users"</span>, {_id: id})
    <span class="kw">if</span> u == <span class="kw">null</span> { <span class="kw">abort</span> <span class="str">"not found"</span> }
    <span class="kw">return</span> u
}</code></pre>

<h3>Find one by indexed field</h3>
<pre><code class="lang-rust">proc by_email(email) {
    <span class="kw">return</span> find_one(<span class="str">"users"</span>, {email: email})
}</code></pre>

<h3>Find with comparison operators</h3>
<pre><code class="lang-rust">proc adults() {
    <span class="kw">return</span> find(<span class="str">"users"</span>, {age: {$gte: <span class="num">18</span>}})
}

proc in_range(min, max) {
    <span class="kw">return</span> find(<span class="str">"users"</span>, {age: {$gte: min, $lte: max}})
}</code></pre>

<h3>Find with <code>$in</code></h3>
<pre><code class="lang-rust">proc by_emails(emails) {
    <span class="kw">return</span> find(<span class="str">"users"</span>, {email: {$in: emails}})
}</code></pre>

<h3>Find with <code>$or</code></h3>
<pre><code class="lang-rust">proc admins_or_owners(team_id) {
    <span class="kw">return</span> find(<span class="str">"members"</span>, {
        team_id: team_id,
        $or: [{role: <span class="str">"admin"</span>}, {role: <span class="str">"owner"</span>}]
    })
}</code></pre>

<h3>Find with regex</h3>
<pre><code class="lang-rust">proc gmail_users() {
    <span class="kw">return</span> find(<span class="str">"users"</span>, {email: {$regex: <span class="str">"@gmail\\.com$"</span>, $options: <span class="str">"i"</span>}})
}</code></pre>

<h3>Find with <code>$exists</code></h3>
<pre><code class="lang-rust">proc has_phone() {
    <span class="kw">return</span> find(<span class="str">"users"</span>, {phone: {$exists: <span class="kw">true</span>}})
}</code></pre>

<h3>Find on nested fields (dot path in query)</h3>
<pre><code class="lang-rust">proc tokyo_users() {
    <span class="kw">return</span> find(<span class="str">"users"</span>, {<span class="str">"address.city"</span>: <span class="str">"Tokyo"</span>})
}</code></pre>

<h3>Empty query = all documents</h3>
<pre><code class="lang-rust">proc all_users() {
    <span class="kw">return</span> find(<span class="str">"users"</span>, {})
}</code></pre>

<h3>Use the result</h3>
<pre><code class="lang-rust">proc summary() {
    let users = find(<span class="str">"users"</span>, {active: <span class="kw">true</span>})
    let total_age = <span class="num">0</span>
    <span class="kw">for</span> u <span class="kw">in</span> users {
        total_age = total_age + u.age
    }
    <span class="kw">return</span> {n: count(<span class="str">"users"</span>, {active: <span class="kw">true</span>}), total_age: total_age}
}</code></pre>

<div class="docs-callout"><strong>Heads-up:</strong> <code>find_one</code> always returns <code>null</code> when nothing matches — never <code>{}</code>. Always guard with <code>if x == null { ... }</code>.</div>
