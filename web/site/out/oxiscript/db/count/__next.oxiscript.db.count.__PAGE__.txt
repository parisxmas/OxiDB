<h2><code>count</code></h2>
<p>Returns the number of documents matching a query — without loading them. With an indexed field, it's O(1).</p>

<h3>Signatures</h3>
<pre><code class="lang-rust">count(collection)
count(collection, query)</code></pre>

<h3>Total count</h3>
<pre><code class="lang-rust">proc total_users() {
    <span class="kw">return</span> count(<span class="str">"users"</span>)
}</code></pre>

<h3>Filtered count</h3>
<pre><code class="lang-rust">proc active_users() {
    <span class="kw">return</span> count(<span class="str">"users"</span>, {active: <span class="kw">true</span>})
}</code></pre>

<h3>Multiple filters</h3>
<pre><code class="lang-rust">proc users_in_range(min, max) {
    <span class="kw">return</span> count(<span class="str">"users"</span>, {age: {$gte: min, $lte: max}, active: <span class="kw">true</span>})
}</code></pre>

<h3>Count as a guard</h3>
<pre><code class="lang-rust">proc enforce_quota(user_id, max_files) {
    let n = count(<span class="str">"files"</span>, {owner: user_id})
    <span class="kw">if</span> n &gt;= max_files { <span class="kw">abort</span> <span class="str">"file limit reached"</span> }
    <span class="kw">return</span> {used: n, allowed: max_files}
}</code></pre>

<h3>Comparison: count vs find length</h3>
<p><code>count</code> is index-friendly and never loads documents. Don't do <code>find(...).length</code>-style patterns — use <code>count</code>.</p>
<div class="docs-grid-2">
  <pre><code class="lang-rust"><span class="co">// SLOW — loads all docs</span>
let xs = find(<span class="str">"users"</span>, {})
<span class="co">// can't get length anyway</span></code></pre>
  <pre><code class="lang-rust"><span class="co">// FAST — index-only</span>
let n = count(<span class="str">"users"</span>, {})</code></pre>
