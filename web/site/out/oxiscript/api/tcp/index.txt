<h2>TCP / OxiWire commands</h2>
<p>OxiScript surfaces six wire commands. All use length-prefixed JSON over the standard OxiDB TCP port (default 4444).</p>

<h3><code>compile_oxiscript</code></h3>
<p>Compile a script to JSON steps without persisting. Useful for syntax checking in CI.</p>
<pre><code class="lang-bash">{<span class="str">"cmd"</span>: <span class="str">"compile_oxiscript"</span>,
 <span class="str">"script"</span>: <span class="str">"proc hi(n) { return {hi: n} }"</span>}</code></pre>
<pre><code class="lang-json">{<span class="str">"ok"</span>: <span class="kw">true</span>, <span class="str">"data"</span>: {
  <span class="str">"name"</span>: <span class="str">"hi"</span>,
  <span class="str">"params"</span>: [<span class="str">"n"</span>],
  <span class="str">"steps"</span>: [{<span class="str">"step"</span>: <span class="str">"return"</span>, <span class="str">"value"</span>: {<span class="str">"hi"</span>: <span class="str">"$param.n"</span>}}]
}}</code></pre>

<h3><code>create_procedure</code></h3>
<p>Compile + persist. Procedure is stored in the <code>_procedures</code> collection.</p>
<pre><code class="lang-bash">{<span class="str">"cmd"</span>: <span class="str">"create_procedure"</span>,
 <span class="str">"script"</span>: <span class="str">"proc hi(n) { return {hi: n} }"</span>}

<span class="co"># Or skip OxiScript and pass a pre-compiled JSON definition:</span>
{<span class="str">"cmd"</span>: <span class="str">"create_procedure"</span>,
 <span class="str">"name"</span>: <span class="str">"hi"</span>,
 <span class="str">"params"</span>: [<span class="str">"n"</span>],
 <span class="str">"steps"</span>: [{<span class="str">"step"</span>: <span class="str">"return"</span>, <span class="str">"value"</span>: {<span class="str">"hi"</span>: <span class="str">"$param.n"</span>}}]}</code></pre>

<h3><code>call_procedure</code></h3>
<pre><code class="lang-bash">{<span class="str">"cmd"</span>: <span class="str">"call_procedure"</span>,
 <span class="str">"name"</span>: <span class="str">"hi"</span>,
 <span class="str">"params"</span>: {<span class="str">"n"</span>: <span class="str">"world"</span>}}</code></pre>
<pre><code class="lang-json"><span class="co">// success</span>
{<span class="str">"ok"</span>: <span class="kw">true</span>, <span class="str">"data"</span>: {<span class="str">"hi"</span>: <span class="str">"world"</span>}}

<span class="co">// abort</span>
{<span class="str">"ok"</span>: <span class="kw">false</span>, <span class="str">"error"</span>: <span class="str">"insufficient funds"</span>}</code></pre>

<h3><code>list_procedures</code></h3>
<pre><code class="lang-bash">{<span class="str">"cmd"</span>: <span class="str">"list_procedures"</span>}</code></pre>
<pre><code class="lang-json">{<span class="str">"ok"</span>: <span class="kw">true</span>, <span class="str">"data"</span>: [<span class="str">"hi"</span>, <span class="str">"transfer"</span>, <span class="str">"place_order"</span>]}</code></pre>

<h3><code>get_procedure</code></h3>
<pre><code class="lang-bash">{<span class="str">"cmd"</span>: <span class="str">"get_procedure"</span>, <span class="str">"name"</span>: <span class="str">"hi"</span>}</code></pre>
<pre><code class="lang-json">{<span class="str">"ok"</span>: <span class="kw">true</span>, <span class="str">"data"</span>: {<span class="str">"name"</span>: <span class="str">"hi"</span>, <span class="str">"params"</span>: [<span class="str">"n"</span>], <span class="str">"steps"</span>: [...]}}</code></pre>

<h3><code>delete_procedure</code></h3>
<pre><code class="lang-bash">{<span class="str">"cmd"</span>: <span class="str">"delete_procedure"</span>, <span class="str">"name"</span>: <span class="str">"hi"</span>}</code></pre>

<h3>Wire format</h3>
<p>Same as the rest of OxiDB: 4-byte little-endian length prefix, then UTF-8 JSON. Max payload 16 MiB.</p>
<pre><code class="lang-python"><span class="kw">import</span> socket, struct, json

s = socket.create_connection((<span class="str">"127.0.0.1"</span>, <span class="num">4444</span>))

<span class="kw">def</span> <span class="fn">call</span>(payload):
    data = json.dumps(payload).encode()
    s.sendall(struct.pack(<span class="str">"&lt;I"</span>, len(data)) + data)
    n = struct.unpack(<span class="str">"&lt;I"</span>, s.recv(<span class="num">4</span>))[<span class="num">0</span>]
    buf = b<span class="str">""</span>
    <span class="kw">while</span> len(buf) &lt; n:
        buf += s.recv(n - len(buf))
    <span class="kw">return</span> json.loads(buf)</code></pre>
