OxiDB vs MongoDB
100K documents 2026-03-17 21:23 22 tests MsgPack wire protocol

A Go test binary (go test) drives both databases through their official client libraries. OxiDB and MongoDB 7 each run in isolated Docker containers with tmpfs storage (pure RAM — no disk I/O variance). The test program connects to both over localhost TCP, inserts 100K identical documents into each, then runs the same queries sequentially — first OxiDB, then MongoDB — measuring wall-clock time for each. OxiDB uses the MsgPack binary wire protocol; MongoDB uses its native BSON/Wire protocol. Indexes are created after insertion and timed separately. Each test is a single cold run (no warm-up iterations).
