OxiDB vs PostgreSQL
100K documents 2026-03-05 22:05 22 tests OxiWire binary protocol
A Go test binary (go test) drives both databases through their official client libraries. OxiDB and PostgreSQL 16 each run in isolated Docker containers with tmpfs storage (pure RAM — no disk I/O variance). PostgreSQL stores documents as JSONB in a single column with expression indexes and native JSONB operators (->>, @>). OxiDB uses its custom OxiWire binary protocol (fixed-size encoding, zero-copy strings); PostgreSQL uses its native wire protocol via pgx. Both have relaxed durability (fsync=off / lazy sync). Each test is a single cold run.
